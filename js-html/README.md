# JavaScript with HTML and CSS — CIS 2336

Open `index.html` in a web browser. No installation or web server is required.

## Suggested teaching order

1. Three ways to add JavaScript
2. Change page content with `textContent`
3. Change CSS with `style` and `classList`
4. Listen for common browser events
5. Read and validate form values
6. Create and remove HTML elements

Each example is intentionally small and includes its HTML, CSS, and JavaScript in an easy-to-read form. Example 1 also demonstrates an external JavaScript file.

## Student practice ideas

- Change the text, colors, and button labels.
- Add a reset button to examples 3 or 4.
- Make pressing Enter add a task in example 6.
- Add another field to the form in example 5.
